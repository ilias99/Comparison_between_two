Le Traître du Sprint

Quatre joueurs ont le même mot. Un seul a un mot voisin. Le mot et le traître sont tirés par la page : personne ne sait qui c'est, même pas celui qui lance la manche.

1. Code de la manche

Poste le même code dans le chat Teams. Tout le monde tape le même, sinon les mots ne correspondent pas.

Manche

2. Découvre ton mot

Touche ton prénom, puis la carte pour voir ton mot. Il ne s'affiche qu'une seule fois par manche. Ne regarde pas celui des autres.

3. Ordre de parole

Chacun donne un seul mot en lien avec le sien. Ensuite 3 minutes de débat, puis vote.

4. Vote et fin de manche

Après le débat, tout le monde vote en même temps. Indique ici qui a le plus de votes. Si c'est le traître, il tente de deviner le mot du groupe. Les points de la manche tombent juste après.

5. Scores

Les points se calculent tout seuls à la fin de chaque manche. Ils restent attachés au code, même si la page est rechargée.

  • S'il n'est pas démasqué : +3 pour le traître.
  • S'il est démasqué mais trouve le mot : +2 pour le traître, +1 pour chaque innocent.
  • S'il est démasqué et rate le mot : +2 pour chaque innocent.
